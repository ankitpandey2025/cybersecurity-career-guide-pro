# Cybersecurity Career Guide — Pro

A full-featured cybersecurity career guidance tool built using HTML, CSS, and JavaScript.  
Runs 100% client-side — no backend required. Perfect for college project submissions.

![Screenshot](screenshots/screenshot-1.png)

## ⭐ Features
- Skill evaluation (sliders)
- Role recommendation with AI-like logic
- Interactive UI with colorful styling
- Save profiles (localStorage)
- View saved profiles
- Analytics charts
- Export JSON / CSV
- Export PDF report
- Export PNG + Photoshop helper
